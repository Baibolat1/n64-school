# Зеркало памяти проекта

Копия заметок из рабочей памяти Claude Code, закреплённая в репозитории, чтобы
конфиг не потерялся вместе с локальным окружением.

**Рабочая копия живёт здесь** (её и читает Claude Code при старте сессии):

```
~/.claude/projects/-workspaces-aiogram-bot/memory/
```

**Этот каталог — зеркало.** Правки, сделанные здесь, сами в рабочую память не
попадут — их нужно переносить руками. Так что менять лучше рабочую копию, а
отсюда забирать актуальное.

Файлы:

- `MEMORY.md` — индекс заметок, по строке на заметку.
- `subagent-workflow.md` — порядок работы через `planner` → `coder` → `reviewer`
  и правило «по умолчанию цепочка выключена».
- `stage-execution-rule.md` — что делаю сам, а что цепочкой (по объёму этапа).
- `project-positioning.md` — соцсеть для учеников, один сайт — одна школа, без мультитенантности.
- `school-site-roadmap.md` — порядок работ, что готово и что осталось.
- `profanity-allowed.md` — мат разрешён, словарей нет, модерация только по жалобам.
- `layout-needs-a-browser.md` — браузера в окружении нет: тесты читают CSS как
  текст, поэтому баги вёрстки проходят мимо набора тестов.

Связанное: сами субагенты лежат в `.claude/agents/`.
