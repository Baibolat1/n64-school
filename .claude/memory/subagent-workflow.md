Субагенты `planner`, `coder`, `reviewer` (`.claude/agents/`) по умолчанию **не запускать**. Обычные задачи выполняю сам, напрямую.

Цепочка включается только по явной просьбе пользователя — например «включи цепочку», «вспомни про цепочку», «сделай через planner → coder → reviewer». Догадок быть не должно: нет прямой просьбы — нет цепочки.

**Why:** пользователь просил не тратить токены на субагентов в обычных задачах.

Для проекта школьного сайта есть конкретное уточнение, какие этапы идут через цепочку, — см. [[stage-execution-rule]].

**How to apply:**
- По умолчанию работаю сам. Не запускать planner «на всякий случай», даже если задача выглядит крупной.
- Когда цепочка включена — порядок такой: planner → показать план пользователю и дождаться «ок» → coder по одному шагу последовательно → reviewer в конце.
- Замечания reviewer'а отдавать обратно `coder`'у на исправление, затем прогонять `reviewer` по исправленному.
- Если цепочку включили, а задача мелкая (правка одной строки) — сказать об этом и предложить сделать напрямую.
